# Definition of Done

An Increment is considered **Done** only when all of the following criteria have been satisfied.

## 1. Acceptance Criteria

- All acceptance criteria associated with the relevant task, issue, or user story have been met.

## 2. Reproducible Workflow

- The analysis can be executed from the original raw data through to the final results using a single, documented workflow.
- Another team member should be able to follow the workflow without requiring undocumented steps.

## 3. Dependencies, Parameters, and Data Sources

- All required dependencies are clearly identified.
- Important parameters and configuration values are documented.
- All data sources used by the analysis are clearly identified.

## 4. Data Transformations

- Data cleaning and transformation steps have been validated.
- Transformations produce the expected structure and values.
- Important assumptions made during data preparation are documented.

## 5. Results Validation

- Results have been checked for errors, inconsistencies, and unexpected values.
- Important calculations have been verified when appropriate.
- Unexpected results have been investigated before the work is considered complete.

## 6. Presentation of Results

- Outputs are presented clearly.
- Tables, summaries, and other results are understandable to the intended audience.
- Labels, units, headings, and descriptions are provided where necessary.

## 7. Visualization Standards

- Visualizations follow the standards agreed upon by the team.
- Charts include appropriate titles, labels, legends, and units when necessary.
- Visualizations accurately represent the underlying data.

## 8. Compatibility with the Next Step

- Outputs are provided in a format that can be consumed by the next stage of the project or workflow.
- File formats, column names, data structures, and interfaces follow the team's agreed conventions.

## 9. Documentation

- Relevant documentation has been created or updated.
- The purpose and use of the new functionality, analysis, or output are explained where appropriate.
- Any important assumptions, limitations, or special instructions are documented.

## 10. Integration with Previous Increments

- The new Increment builds upon all previous Increments.
- Existing functionality and workflows continue to work as expected.
- Changes do not introduce regressions or break previously completed work.

## 11. Storage of Results

- Results are stored in the location agreed upon by the team.
- Files follow the team's agreed naming conventions and formats.
- Outputs required by other team members are accessible and organized appropriately.

---

## Completion Checklist

Before marking an issue or Increment as **Done**, confirm that:

- [ ] All acceptance criteria have been met.
- [ ] The complete workflow can be executed from raw data to final results.
- [ ] Dependencies, parameters, and data sources are documented.
- [ ] Data transformations have been validated.
- [ ] Results have been checked for inconsistencies.
- [ ] Outputs are clear and interpretable.
- [ ] Visualizations follow team standards.
- [ ] Outputs can be consumed by the next step in the workflow.
- [ ] Documentation has been created or updated.
- [ ] Previous functionality and workflows still work correctly.
- [ ] Results are stored in the agreed location and format.

If any of these requirements are not satisfied, the work should not yet be considered **Done**.
